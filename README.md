# DevOps Git Challenge

## Overview
This repository contains the practical work for the DevOps version control activity.

## Objectives
- Practice Git configuration and repository management.
- Create and manage branches.
- Use Git stash to save unfinished changes.
- Simulate and resolve a merge conflict.
- Create and merge a pull request using GitHub.

## Files
- `deploy.sh`: A simple deployment script.
- `README.md`: Project description and activity overview.
